# 机加工 AI 智能报价系统：业务功能总结与汇报 PPT 大纲

## 一、汇报定位

- **建议受众**：管理层、报价/工艺负责人、业务使用部门。
- **汇报目标**：说明系统如何把 CAD 图纸、人工工艺判断与企业成本规则串成可审核、可追溯、可导出的报价闭环；重点展示材料双计价与形状目录化、AI 流式报价建议两项能力。
- **核心结论**：系统不是让 AI 直接“拍价”，而是以确定性公式负责金额计算，以 AI 负责图纸理解、工艺建议和遗漏检查，并把人工确认保留在最终决策链路中。
- **建议页数**：10-12页。

## 二、系统全流程业务功能总结

### 1. 报价业务主线

```text
CAD 图纸上传
  → AI/CAD 解析（格式、尺寸、三维模型、特征）
  → 人工确认特征、材料规格、产品规格和工序
  → 成本引擎按企业公式计算
  → AI 流式输出工艺/风险/优化建议
  → 规则层 + 语义层 AI 审核、人工审核
  → 导出 Excel 核价单并沉淀历史报价
```

| 环节 | 业务功能 | 业务价值 |
|---|---|---|
| 报价受理 | 上传 DWG、DXF、STEP、STP 图纸，建立报价任务 | 将图纸与报价记录绑定，减少线下资料散落 |
| 图纸解析 | 识别 CAD 格式、几何尺寸、三维模型和结构特征；支持三维预览与特征定位 | 将“看图”前置为可复核的数据输入 |
| 参数确认 | 录入/修正物料编码、描述、材料、毛坯与成品规格、MOQ、调机费、良率 | 把 AI 解析结果转化为业务确认后的报价依据 |
| 工艺确认 | 选择或维护工站；支持按时长、百分比、重量、固定金额四类计费 | 工艺经验可被复用，且能覆盖不同费用口径 |
| 成本计算 | 执行材料、机加工、附加费用、管销、利润、税、样品倍率、良率和调机费的公式链 | 同一输入得到同一结果，价格可解释、可复算 |
| AI 建议 | 根据确认后的规格、重量、特征摘要、已选工序给出材料、工艺、风险与优化建议 | 在人工报价过程中补足工艺判断与风险提醒 |
| 审核交付 | 本地规则检查、AI 语义质检、人工审核、导出 Excel 核价单 | 形成“发现问题—回到参数修改—复审—交付”的闭环 |
| 目录与历史 | 材料价格、形状、工站、策略全局复用；报价保留价格/工艺/策略快照 | 目录可持续维护，历史报价不因后续目录变化失真 |

### 2. 报价成本与可追溯性

系统将本次报价的材料单价、计价方式、工序、费率与策略保存在报价快照中，并记录每一段公式。当前公式链为：

```text
K 材料成本
  → R 机加工成本
  → 附加费用（损耗/重量型/固定型）
  → S 管销
  → T 小计
  → U 利润
  → V 含税成本
  → W 样品价格
  → 良率调整后的报价单价
  → 总价（单价 × 数量 + 调机费）
```

- **材料成本 K**：按形状确定计价方式，分别支持 `毛重 × 元/kg` 或 `直接价格`。
- **机加工成本 R**：时间型工序按 `工费率 ÷ 60 × 加工分钟数` 汇总。
- **附加费用**：支持按机加工成本比例、按净重、按人工输入金额三种方式。
- **价格调整**：支持管销、利润、税率、样品倍率、良率、MOQ 和调机费；良率填写后按 `W ÷ 良率` 调整单价。
- **余料**：自动记录 `毛重 − 净重` 和余料单价，仅用于留档与报价单展示，不参与本次价格计算。

## 三、重点专题一：材料双计价体系与形状目录化

### 业务问题

机加工材料既有按重量采购/计价的常规毛坯，也有按根、按件或其他直接金额口径计价的非标物料。如果材料、形状、重量和单价单位可任意组合，容易发生“按根材料却按 kg 乘毛重”等错误。

### 系统设计与控制逻辑

| 能力 | 系统规则 | 结果 |
|---|---|---|
| 双计价 | **重量计价**：`K = 毛重 × 元/kg`；**直接计价**：`K = 直接价格` | 同一成本引擎覆盖常规与非标材料 |
| 形状驱动 | 预置“方块、球体”固定走重量计价；新增自定义形状固定走直接计价 | 计价单位从源头与形状绑定 |
| 自动算重 | 方块按 `长×宽×厚×密度`，球体按体积×密度；毛重、净重均可在系统计算后人工覆盖 | 降低手工换算与单位错误 |
| 目录复用 | 形状、材料、材料密度、当前价格、工站和策略在后续报价中可直接复用 | 报价员无需重复创建基础数据 |
| 四道校验 | 下拉仅展示匹配计价方式的材料；切换形状清空不匹配材料；新增材料继承当前形状的计价方式；恢复历史会话时再次校验 | 避免形成错误的材料/形状/单位组合 |
| 快照保护 | 本次报价固定保存单价、确认时间、来源、价格类型、工序和策略 | 目录更新不影响历史报价复盘 |

### 重点页建议截图

![材料与形状确认界面](brief-assets/material-shape-pricing-form.png)

**建议在截图右侧加 3 个标注**：

1. “方块（自动算重 · 元/kg）”：形状决定当前计价语义。
2. “S31603 不锈钢（¥38.00/kg · 已确认）”：材料目录携带单价和确认信息。
3. “毛重、净重、余料、良率”：自动计算与人工业务确认并存。

## 四、重点专题二：AI 报价建议（流式升级）

### 升级目标

将“等待 AI 完整返回后一次性展示”升级为“任务一开始即进入交付页，生成过程分段可见”。用户能及时看到推理进度、建议逐步成形，并可取消任务而不继续消耗上游模型调用。

### 实现的业务体验

- **双通道流式输出**：模型推理文本与正文增量分别传递，前端优先给出进度反馈；完成后以结构化结果为准。
- **分区增量呈现**：材料推荐、工艺建议、风险提示、优化建议四个区域以骨架屏开始，内容生成后逐块填充。
- **可取消/可降级**：返回上一步会中止当前调用；流式通道异常时自动回退到非流式报价接口。
- **输入瘦身**：CAD 特征由逐条明细压缩为分类汇总与代表性特征，再交给 AI 分析；项目记录显示单次输入约由 10.5k 降至 1.1k token，约降低 90%。
- **价格保护**：AI 报价建议输入不包含材料单价；AI 做工艺与风险判断，金额仍由确定性公式引擎计算。
- **输出收敛**：工艺建议限制为最多 5 条，风险和优化建议分别最多 4 条，适配报价员等待场景。

![AI 报价建议与语义审核界面](brief-assets/quote-detail-ai.png)

**建议在截图上方用一句话收束**：

> AI 不替代定价公式，而是基于已确认规格和工序，持续补全工艺建议、风险点与修改入口。

截图同时可展示两个闭环：左侧是“材料/工艺/风险/优化”四类报价建议，右侧是“规则层通过 + 语义层发现具体遗漏”，并可一键返回“工序确认”修改。

## 五、简报 PPT 大纲（12 页）

### P1 封面｜机加工 AI 智能报价系统业务简报

- 副标题：从 CAD 图纸到可审核核价单的端到端报价闭环。
- 视觉：深色制造工作台背景，使用图纸上传工作台截图的局部。
- 讲述重点：明确本次汇报围绕“报价效率、报价一致性、风险可控”三件事展开。

### P2 为什么要做｜传统报价依赖经验，难复用、难追溯

- 现状痛点：图纸解读靠人工、工艺和费用项容易遗漏、材料单位口径混杂、历史报价难复盘。
- 对应目标：将图纸、参数、规则、审核和核价单整合为统一业务链路。
- 结论：系统的价值是把个人经验转为可配置、可审核的组织能力。

### P3 系统全景｜一条报价任务贯通八个业务环节

- 用横向流程呈现：上传 → 解析 → 确认 → 工艺 → 计算 → AI 建议 → 审核 → 导出/沉淀。
- 讲清分工：CAD/AI 负责理解与提示；人工负责确认与决策；计算引擎负责金额。
- 视觉：可使用 [业务总流程图](diagrams/business-overall-flow.svg) 作为辅助图。

### P4 图纸到参数｜把 CAD 信息转化为可核对的报价输入

- 支持 DWG、DXF、STEP、STP；解析尺寸、三维模型和特征。
- 报价员在三维预览与特征列表旁确认材料规格、成品规格、MOQ、良率与工序。
- 价值：将“看图经验”转成“有依据的人工确认”。
- 截图：`brief-assets/material-shape-pricing.png`（工作台与特征确认视图）。

### P5 成本计算｜企业公式链驱动，可解释、可复算

- 展示公式链：K → R → 附加 → S → T → U → V → W → 良率 → 总价。
- 明确费用口径：材料、机加工、损耗、重量型表处、固定附加、管销、利润、税、样品倍率、调机费。
- 强调每段计算式、单价、工序和策略均被保存到本次报价快照。

### P6 重点一｜材料双计价：让不同采购口径进入同一报价体系

- 对比两种公式：
  - 重量计价：`K = 毛重 × 元/kg`
  - 直接计价：`K = 直接价格`
- 说明收益：既支持标准方/圆料，也支持按根、按件等非标材料；避免单位错乘。
- 讲清原则：AI 不接收材料单价，金额仍由确定性公式产生。

### P7 重点一｜形状目录化：将单位、算重和材料选择联动约束

- 展示“方块/球体 = 自动算重 + 元/kg；自定义形状 = 直接价”的配置逻辑。
- 说明自动计算：密度 × 尺寸得到毛重/净重；余料自动记录但不计入本次价格。
- 说明四道防线与快照保护，突出“减少错误组合、保护历史结果”。
- **主截图**：`brief-assets/material-shape-pricing-form.png`。

### P8 目录资产化｜材料、形状、工站、策略一次维护，多次复用

- 材料目录：牌号、密度、价格、确认时间、来源与历史价格。
- 形状目录：预置形状保护自动算重规则；自定义形状可复用。
- 工站目录：按时长/比例/重量/固定金额四类费用建模，历史报价保留工艺快照。
- 策略目录：损耗、管销、利润、税、样品倍率、调机费等统一配置。

### P9 重点二｜AI 报价建议流式升级：从“等待结果”到“生成可见”

- 流程：点击“生成 AI 报价建议” → 即刻进入交付页 → 推理/正文双通道增量回传 → 四类建议逐块生成 → 完成后结构化落库。
- 体验：骨架屏、实时进度、思考面板自动跟随、用户可取消、异常自动降级。
- 成本效率：特征摘要输入瘦身，项目记录为约 10.5k → 1.1k token（约 -90%）。

### P10 重点二｜AI 建议与审核闭环：提出问题，也提供回改入口

- 报价建议四类输出：材料推荐、工艺建议、风险提示、优化建议。
- 审核双层：本地规则层即时给出基础结论；AI 语义层检查工序完整性、特征-工序匹配、时长合理性、规格自洽、公差匹配和历史漂移。
- 强调：每条问题带有依据和“去修改”位置，修改后可重新审核。
- **主截图**：`brief-assets/quote-detail-ai.png`。

### P11 报价交付与治理｜从一次报价到可持续的业务资产

- 报价详情呈现成本明细、计算方法、CAD 特征、AI 建议与审核记录。
- 人工审核通过后导出 Excel 核价单；报价记录保留图纸关联、价格快照、工序快照和策略版本。
- 业务价值：可交付、可审计、可比较、可用于后续历史基线。

### P12 下一步建议｜从“全流程可用”走向“规则持续对齐”

- 优先项 1：确认损耗基数、管销形态、废料抵扣、圆柱体算重等业务分歧。
- 优先项 2：补充圆柱体等高频形状并维护目录。
- 优先项 3：收敛产品级追溯字段（品名、物料描述、图号）和正式环境部署方案。
- 收束句：以“确定性成本规则 + AI 辅助判断 + 人工审核”为长期报价治理框架。

## 六、汇报制作建议

- **风格**：沿用系统的深蓝/青绿色调；制造感、专业感优先，避免过多科技装饰。
- **讲述比例**：P1–P5 约 35%，材料与形状专题 P6–P8 约 35%，AI 流式专题 P9–P10 约 25%，P11–P12 约 5%。
- **截图原则**：保留真实系统状态与真实报价数据，重点用方框/引线解释字段；不要用模拟界面替换真实流程截图。
- **事实边界**：资料中 README 的 SQLite 描述属于早期说明；当前后端连接与实际运行数据为 MySQL。正式汇报应以当前系统实现为准。
