# 机加工智能报价系统上线交付清单

## 首次部署

1. 准备可供本系统连接的 MySQL 数据库账号与数据库。
2. 基于 `backend/.env.example` 创建生产 `.env`，配置数据库、`AUTH_TOKEN_SECRET` 与初始管理员账号密码。密钥不得进入 Git、截图或工单。
3. 在部署环境执行 `npm ci`；服务启动时会自动创建或更新数据表及首次管理员。
4. 构建前端：`cd frontend && npm run build`。部署服务启动前，确认 `frontend/build/index.html` 存在。
5. 设置 `NODE_ENV=production`，使用 HTTPS 反向代理运行后端；健康检查使用 `/health`，就绪检查使用 `/ready`。
6. 管理员首次登录后修改初始密码，并从部署环境移除 `ADMIN_INITIAL_PASSWORD`。

## 每次发布

1. 发布前备份数据库；新版本服务启动时会自动确保数据库结构可用。
2. 执行 `cd backend && npm test`、`cd frontend && npm run build`。
3. 以管理员身份验证：登录、上传有效与伪造扩展名图纸、解析、AI 降级、计算、审核、导出、退出后访问 API 被拒绝。
4. 发布前备份 MySQL；发布后调用 `/ready` 并抽查一份已核准样本报价。

## 运行维护

- 每日备份 MySQL，至少每季度进行一次恢复演练；备份文件加密并限制访问。
- 未关联报价的过期图纸默认保留 90 天；报价人工审核通过并进入“已完成”后，原始 CAD 图纸及三维缓存会立即清理，保留结构化识别结果、工序、报价和审核记录。
- 监控 `/ready`、磁盘空间、CAD 解析超时/排队、AI 降级、429 限流与 5xx 错误；使用日志中的 `X-Request-Id` 追踪问题。
- 管理员账号、材料价格、工站、策略和报价写操作会写入 `audit_logs`，用于事后追溯。
