# 🤖 机加工AI智能报价系统

一个基于DeepSeek AI的机加工智能报价系统，支持图纸自动分析、参数提取、智能报价计算。

## ✨ 功能特点

### 🎯 核心功能
- **AI图纸分析**: 自动识别零件特征、材料、尺寸等参数
- **智能报价引擎**: 基于AI分析的成本计算
- **3D模型可视化**: 支持CAD文件查看
- **AI审核建议**: 自动检测报价合理性
- **PDF报价单导出**: 一键生成规范报价单

### 🔧 技术特性
- 支持DWG, DXF, STEP, STP, PNG, JPG, JPEG, PDF等格式
- 基于DeepSeek Vision模型的智能分析
- 完整的工序分解和工时计算
- 灵活的参数调整和优化建议
- 响应式的Web界面

## 🚀 快速开始

### 前置要求
- Node.js 18+
- DeepSeek API Key

### 1. 安装依赖

```bash
# 后端依赖
cd backend
npm install

# 前端依赖
cd ../frontend
npm install
```

### 2. 配置环境变量

```bash
cd backend
cp .env.example .env
# 编辑 .env 文件，填入你的 DeepSeek API Key
```

配置内容:
```env
DEEPSEEK_API_KEY=your_deepseek_api_key_here
DEEPSEEK_API_BASE=https://api.deepseek.com
UPLOAD_DIR=./uploads
PORT=3001
NODE_ENV=development
```

### DWG 解析配置

DWG 是二进制格式。项目使用内置的 `dwgdxf` WebAssembly 依赖在服务端将其转换为 DXF，再提取实体、边界和特征；无需安装 AutoCAD、ODA File Converter 或配置额外环境变量。当前支持 AutoCAD R13 至 R2018（`AC1012`–`AC1032`）格式的 DWG 文件。

### 3. 初始化数据库

```bash
cd backend
npm run init-db
```

### 4. 启动服务

```bash
# 启动后端 (在 backend 目录)
npm run dev

# 启动前端 (在 frontend 目录, 另一个终端)
cd ../frontend
npm start
```

### 5. 访问应用

打开浏览器访问: http://localhost:3000

## 📖 使用指南

### 方式一: AI智能报价 (推荐)

1. 点击导航栏 "🤖 AI智能报价"
2. 上传图纸文件（支持DWG/DXF/STEP/PNG/JPG等）
3. 填写基本信息（可选，AI会尝试提取）
4. 点击"下一步"，等待AI分析图纸
5. 查看AI提取的参数，确认或修改
6. 点击"计算报价"，生成详细报价单
7. 查看AI报价建议，完成报价

### 方式二: 手动报价

1. 点击导航栏 "新建报价"
2. 手动填写所有零件参数
3. 计算报价并导出

### 报价计算说明

系统会自动计算以下费用:
- **材料成本**: 基于体积、密度和材料单价
- **人工成本**: 基于复杂度和精度要求
- **设备费用**: 基于加工工序和设备使用
- **管理费用**: 总成本的15%
- **利润**: 总成本的20%

## 🔧 配置说明

### DeepSeek API

1. 注册 DeepSeek 账号: https://platform.deepseek.com/
2. 获取 API Key
3. 填入后端 .env 文件中

### 文件大小限制

默认限制最大文件大小为 50MB，可在 .env 文件中修改。

## 🔐 安全说明

- API Key 存储在后端环境变量中，不会暴露给前端

- 建议在生产环境中添加用户认证和文件病毒扫描
